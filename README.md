# 🛒 쇼핑 리스트 앱

브라우저에서 바로 실행되는 한국어 쇼핑 리스트 웹 앱입니다.

## 기능

- 아이템 추가 (Enter 키 또는 + 버튼)
- 체크/체크 해제 (완료 토글)
- 개별 아이템 삭제
- 완료 항목 일괄 삭제
- `localStorage`로 데이터 자동 저장 (새로고침 후에도 유지)

## 실행 방법

`shopping-list.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

## 테스트 실행

```bash
npm install
npm test
```

Playwright를 사용한 자동화 테스트 (총 22개 케이스)가 실행됩니다.
